# SalesReporterApp

SENG 21222 - Software Construction - Assignment 1

## Run

Console:
java -cp target/classes lk.salesreporter.Main data/sales.csv console

File:
java -cp target/classes lk.salesreporter.Main data/sales.csv file report.txt

## Requirements covered

- Revenue per product
- Revenue per category
- Best-selling product
- Highest revenue product
- Grand total revenue
- Console/file output strategy
- CSV header handling
- Error handling
- JUnit tests
- SOLID-oriented structure
